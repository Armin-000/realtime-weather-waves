## 🛰 APIs

| API | Purpose |
|---|---|
| Open-Meteo Forecast API | Temperature, wind, sunrise/sunset |
| Open-Meteo Marine API | Wave height, wave direction, swell |
| Open-Meteo Geocoding API | Location search & coordinates |
